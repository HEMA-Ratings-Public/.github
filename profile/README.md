## HEMA Ratings

**HEMA Ratings** is a platform for tracking, comparing, and exploring competitive results in Historical European Martial Arts (HEMA).

Our goal is to make tournament results and ratings accessible to the HEMA community, while providing event organizers with the tools for seeding and running their events.

## Our projects

This GitHub organization hosts the open-source projects behind HEMA Ratings. The goal is to get all public-facing projects such as the main page and the submitter in a state where they can be published here.

- **Website:** [submit.hemaratings.com](https://submit.hemaratings.com)
